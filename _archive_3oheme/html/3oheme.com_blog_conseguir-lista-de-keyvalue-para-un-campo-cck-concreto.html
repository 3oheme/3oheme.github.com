Conseguir lista de key|value para un campo CCK concreto

3oheme, 22 Febrero 2011

Muy sencillo: si nuestro campo se llama 'field_categoria' solo tenemos que hacer lo siguiente:

$field = content_fields('field_categoria');
$values = content_allowed_values($field);

Y listo. En la variable $values tenemos un array con los diferentes valores que puede coger ese campo CCK (gracias a Jacinto por la ayuda)

  • $node
  • CCK
  • content_allowed_fields
  • content_fields
  • maquetación
  • theming
El contenido de este campo se mantiene privado y no se mostrará públicamente.
