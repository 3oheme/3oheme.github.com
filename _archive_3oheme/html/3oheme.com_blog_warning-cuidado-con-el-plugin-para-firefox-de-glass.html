Warning! cuidado con el plugin para Firefox de Glass

3oheme, 17 noviembre 2010

Antes que nada la versión corta del post:

Si eres webdeveloper, mucho cuidado con el plugin para Firefox de Glass, porque interfiere con el funcionamiento correcto de firebug y añade clases y CSS que provocan errores en la visualización de las páginas.

Glass es una nueva red social, fundada por antiguos trabajadores de Google, que se mueve en el rollo de poder dejar comentarios a tus colegas en cualquier web (en el vídeo demostrativo explican el concepto, que por otro lado no es nada nuevo, ver google sidewiki, reframeit o komenti).

El problema viene en que el plugin de Glass añade marcado html+css a cualquier web que visitemos, y en el último desarrollo que he realizado en Alquimia he encontrado que ese marcado hace que las imágenes que apliques sobre el body con css den problemas al ajustarlas con bottom left. Sí, un issue bien raro, pero que te puede tener 10 minutos peleándote con el código hasta que des con la fuente del error.

Así que ya sabéis, si sois desarrolladores web al plugin de Glass le pueden ir dando por culo.
