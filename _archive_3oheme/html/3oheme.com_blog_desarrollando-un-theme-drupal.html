Desarrollando un theme Drupal

3oheme, 17 octubre 2010

Hey! Solo decir públicamente que comienzo el desarrollo de un theme para Drupal 6.x. Todavía no tiene nombre, pero el estilo que seguirá será el de un periódico clásico, e incorporará las siguientes power features:

  • Utilización de Google webfonts para mejorar el aspecto sin tener que meter flash
  • Layout 960, con multitud de regiones, combinaciones de una/dos columnas, contenido principal antes de las demás regiones, uso de footer/mission, SEO friendly...
  • Múltiples herramientas para desarrollar con el theme: opción para añadir fondo grid 960, conteo de scripts/css para evitar el bug de los 30 includes en Explorer, ayudas para breadcrumb, enlaces para editar bloques...
  • Graceful degradation para IE6-7 y otros navegadores
  • Incluirá diferentes estilos, seleccionables simplemente con un selectbox, cambiando fuentes, colores, texturas, etcétera

Ah, y dar las gracias a Alquimia por colaborar con servidores, infraestructura y ayuda diversa.

Ya iré informando de las novedades vía blog. Y si alguien tiene alguna sugerencia la puede dejar en los comentarios :-)
