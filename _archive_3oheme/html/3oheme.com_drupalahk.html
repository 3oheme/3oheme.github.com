Drupal autohotkeys

Descargar versión 1.0

Yuhu! desde las profundidades de 3oheme.com emergen las Drupal Autohotkeys, un pequeño script en formato AutoHotKeys en (versión autoejecutable y como script ahk) que te permite moverte con mayor velocidad por las rutas más utilizadas en una instalación Drupal.

Especificaciones

  • Funciona bajo Windows XP, vista y Windows 7
  • Compatible con Firefox y Chrome

¿Cómo lo utilizo?

  • Ejecuta primero drupalAHK.exe
  • Ejecuta tu navegador Firefox o Chrome y accede a tu página Drupal
  • Pulsa CTRL+WIN+m y te redirigirá a http://www.tupagina.com/admin/build/modules. Rápido y fácil :-D
  • Para todo el listado de atajos de teclado, al final de esta página tienes una tabla resumen

Para mayor comodidad puedes copiar el fichero drupalahk.exe a Inicio para que se ejecute al iniciar Windows.

Extra bonus!

Si eres de los que necesitan texto lorem ipsum para crear nodos y texto de prueba, con la combinación CTRL+WIN+l tendrás en el portapapeles un texto lorem ipsum aleatorio. Genial, ¿eh?

Lista de atajos de teclado

Combinación de teclas Acción
CTRL+WIN+m admin/build/modules
CTRL+WIN+t admin/content/types
CTRL+WIN+n admin/content/node
CTRL+WIN+b admin/build/block
CTRL+WIN+c devel/cache/clear
CTRL+WIN+s admin/build/translate/search
CTRL+WIN+a node/add
CTRL+WIN+u admin/user/user
CTRL+WIN+i admin/build/imagecache
CTRL+WIN+p admin/user/permissions
CTRL+WIN+e admin/build/menu
CTRL+WIN+v admin/build/views
CTRL+WIN+t admin/content/taxonomy
CTRL+WIN+l Copia al portapapeles un texto de tipo lorem ipsum aleatorio ¡bonus!
